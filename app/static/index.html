Interactive stochastic spatial model

Virus Spillover Simulator

This toy example illustrates a possible application to Nipah virus spillover in Bangladesh. Kr(x) is the spatial reservoir density of Pteropus medius bats, P(x, θ) is the Nipah pathogen density, Ks(x) is human density (the spillover host), and α(x) is a covariate corresponding to date-palm consumption. The example is illustrative rather than calibrated: several parameter values should be adjusted against epidemiological data before the outputs are interpreted as realistic.

This web-app was developed in the framework of the European BCOMING project.

How to read the model

Mechanism

  1. Reservoir smoothing. Kr is the spatial bat-reservoir density and is convolved with the Gaussian spatial kernel JD.
  2. Pathogen trait. G is the standard Gaussian density, so the pathogen trait θ is distributed as N(0,1).
  3. Marked Poisson spillover. Primary human infections appear in Ks with intensity proportional to (β0 + β1α(x)) Ks(x) P(x, θ).
  4. Branching transmission. Each primary infection starts an independent continuous-time birth-death process. The birth parameter controls onward transmission and the death/removal parameter controls chain termination; together they determine the length of transmission chains. Growth is favored when b0 > d0 + (θ - Os)2.
